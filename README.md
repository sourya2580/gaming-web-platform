# 🎮 Gaming Web Platform

> A responsive gaming website with modern UI and smooth user experience.

## 📌 Problem
Gaming sites often suffer from cluttered UIs and poor responsiveness across devices.

## 💡 Solution
A clean, responsive gaming platform built with a modern frontend stack for smooth navigation and gameplay browsing.

## ⚙️ Tech Stack
- **Frontend:** React, Next.js, TypeScript
- **Styling:** HTML, CSS

## 🧠 Key Learnings
- Component-based architecture with React
- SSR/routing with Next.js
- Responsive design across screen sizes

## 🔧 How to Run
```bash
git clone https://github.com/sourya2580/gaming-web
cd gaming-web
npm install
npm run dev
```
